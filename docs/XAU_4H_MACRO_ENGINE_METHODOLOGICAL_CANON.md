## O que NÃO fazer mais
A frente **não deve mais ser conduzida como busca de filtros/gates sobre realR capado ou teaching-set agregado.**
Otimização agregada (sumR/WR/PF/DD, permutation como guilhotina, "sample-thinning dentro do ruído") trata trades
como fungíveis, usa outcome capado como árbitro e é cega à convergência — falso ao objetivo. Ver

## Correção canônica (8 pontos, ordenados por prioridade causal)
1. **Causalidade vem primeiro.** Close-only shift1; daily/weekly D-1; SMC/OB/bubbles SHIFT1 (repintam); volume
   só Session VP REAL (tick-volume não-confiável). Sem isto, nada acima vale.
2. **D1/weekly macro backbone é CONTEXTO, não gate duro.** Preserva bull; isola só o macro-bear-markdown-leg.
   NUNCA deixar escalar regimeB lagging sobrepor uma bull-leg confirmada. LONG roda sem regime-gating (validado).
3. **O edge vive na CONVERGÊNCIA multifatorial** — Auction/estrutura (supply clean-sky vs colada, demand
   defendida) / volumetria (SVP real) / MTF / momentum (legpos×momentum) / capitulação-clímax / fuel / risco.
   Sinal = convergência de fatores ortogonais fracos (capit+rsi), nunca um fator isolado passando significância.
4. **Risk/SL/exit estrutural é EIXO PRÓPRIO** (ortogonal). SL por estrutura defendida (não tight, sem teto 1.5;
   >4ATR = review humano); exit por perfil do trade; convexidade/monumentais preservados. É onde muitos "losers"
   na verdade estão (skip-que-deveria-ser-winner = estrutura boa stopada por gestão, não por entrada).
5. **Outcome/realR capado é FEEDBACK DE CALIBRAÇÃO, não predicado nem árbitro principal.** realR está capado
   +3.9R → magnitude = hit-rate, não expectancy. Classificar por TIPO DE SAÍDA (WIN bateu+2R / STOP / SCRATCH
   time-exit), nunca por R-sign quando o SL é grande.
6. **Avaliação correta = leitura estrutural trade-a-trade + tipo de saída**, por episódio com lift sobre
   base-rate, preservando convexidade e monumentais — para EXPLICAR cada mislabel (winner-que-é-skip /
   skip-que-é-winner), não para subir um agregado.
7. **Não repetir busca superficial de feature/gate.** Melhorar o engine ≠ filtro novo sobre os 276 (overfit no
   drift bull garantido; A1' mode). Validação real exige OOS/regime não-bull (bear 2013-2016 já coletado = Opção B).
8. **Specs/refutações anteriores são REINTERPRETADAS dentro deste sistema integrado, não descartadas.** Fraqueza
   isolada ≠ inútil ([[feedback_prior_layers_conditional_evidence]]); toda camada antiga entra como evidência
   condicional sob o backbone correto. Não chamar "refutado" o que foi implementação ingênua subperformando.
